# Climate Action
This website is designed to raise awareness about climate change and encourage people to adopt more sustainable habits through daily tasks, rewards, and educational information.
The website is divided into three main sections:

INFORMATION

This section provides educational information about climate change, including:

What climate change is.
How it affects our planet and our daily lives.
The main causes of climate change.
The environmental and social consequences it can generate.
Possible solutions and actions that can help reduce its impact.

The purpose of this section is to help users understand the problem before encouraging them to take action.

TASKS

In this section, users receive different tasks that they can complete in their everyday lives.

Each task includes:

A description of the action to perform.
An explanation of how that action can help the environment.
The number of points the user will receive after completing it.

For example, a task could ask the user to recycle their waste, use public transportation, save water, or reduce unnecessary energy consumption.

By completing these tasks, users earn points and make progress on their profile.

PROFILE

The profile section allows users to keep track of their progress.

Here, users can see:

Their current level.
Their total number of points.
Their completed tasks.
Their achievements.
A progress bar showing how close they are to reaching the next level.

The leveling system is based on the points earned by completing tasks. This adds a gamification system to the website, encouraging users to continue completing environmentally friendly actions.

# PURPOSE OF THE PROJECT

The main goal of this project is not only to provide information about climate change, but also to encourage users to take practical actions in their everyday lives.

Instead of simply telling people that climate change is a problem, the website attempts to turn environmental awareness into small, achievable actions.

# FUTURE DEVELOPMENT

In the future, the project could be expanded with additional features, such as:

Daily and weekly challenges to encourage users to return regularly.
Achievement badges for reaching specific goals.
Streaks for completing tasks on consecutive days.
More task categories, such as transportation, recycling, energy, water, and food.
Personalized tasks based on the user's habits.
A leaderboard where users can compare their progress.
A database to save user profiles and their progress.
More detailed statistics showing the user's environmental actions over time.

The long-term goal would be to turn the project into an interactive platform that combines education, motivation, and real-world environmental action.
